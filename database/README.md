# Databases

One MySQL database per service (`talkie_<service>`); a service never reads another service's database.
Migrations are applied in file order by `npm run db:migrate` and recorded in each database's `schema_migrations`.
Never edit an applied migration — add a new numbered file.

Conventions:
- `BIGINT UNSIGNED` Snowflake primary keys generated by the application (time-ordered).
- `DATETIME(3)` in UTC.
- InnoDB, `utf8mb4` (emoji-safe).
- Every foreign key and every list query has an index; list queries use keyset pagination on `id`.
- `outbox` = transactional outbox for publishing events; `processed_events` = consumer de-duplication.
- Works on MySQL 8.0+ (production) and MariaDB 10.4+ (local development).
